## §4 Task-Type Playbooks from Human Demonstrations [AITW 714,446 eps]

> Per category: tactic + measured high-frequency action transitions + step estimate.

### settings toggle | #k: turn on,turn off,toggle,enable,disable,switch
- Tactic: Settings toggles: open Settings → search bar type keyword (fastest) OR drill into category → tap the toggle; switch state itself is the completion signal
- Frequent transitions: SWIPE_UP → TAP '[ICON_SETTINGS]' ×65; HOME → SWIPE_UP ×32; BACK → SWIPE_UP ×13; TAP '[ICON_SETTINGS]' → SWIPE_UP ×10; TAP '[ICON_SETTINGS]' → SWIPE_DOWN ×9
- Step estimate: median 8

### search | #k: search,find,look up
- Tactic: Search flow: locate search box (magnifier / search-bar text) → tap → TYPE keyword → ENTER; result page appearing = done
- Frequent transitions: SWIPE_UP → TAP '[ICON_SETTINGS]' ×37; HOME → SWIPE_UP ×24; SWIPE_UP → TAP '[ICON_LOCATION]' ×7; TAP 'Accept & continue' → TAP 'Continue' ×6; BACK → SWIPE_UP ×6
