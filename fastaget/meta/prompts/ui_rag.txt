### Icon Button Semantics | #pull-on: icon,element,tap,observe,find
- [ICON_MAGNIFYING_GLASS] = magnifier — search; usually top of page/toolbar
- [ICON_THREE_DOTS] = ⋮ vertical dots — more options/menu; top-right
- [ICON_THREE_BARS] = ☰ hamburger — navigation drawer; top-left
- [ICON_PLAY] = ▶ triangle — play/launch. In app lists it is an app icon; in media UI a play control — check context
- [ICON_SETTINGS] = ⚙ gear — settings/config; toolbar or menu
- [ICON_X] = ✕ cross — close/clear/cancel; dialog top-right or inside search box
- [ICON_ARROW_BACKWARD] = ← left arrow — back to previous page; top-left
- [ICON_ARROW_UPWARD] = ↑ up arrow — expand panel / scroll up
- [ICON_PLUS] = ＋ plus — create/add new; list bottom-right (FAB)
- [ICON_SHOPPING_CART] = 🛒 cart — view shopping cart; e-commerce nav bar
- [ICON_STAR] = ★ star — favorite/mark/rate; list item or detail page
- [ICON_TAKE_PHOTO] = 📷 camera — photo/scan; bottom action bar

- [ICON_V_DOWNWARD] = ▼ chevron down — expand menu / dropdown
- [ICON_LAUNCH_APPS] = ⊞ grid — view all apps; bottom nav bar
- [ICON_CHAT] = 💬 bubble — message/conversation; messaging apps
- [ICON_LOCATION] = 📍 pin — location/map; map apps or nav bar
- [ICON_NAV_BAR_CIRCLE] = ◉ circle — system Home button; bottom nav bar
- [ICON_INFO] = ℹ circled i — details/help; settings or detail page
- [ICON_EDIT] = ✎ pencil — edit; content detail or toolbar
- [ICON_ASSISTANT] = assistant glyph — voice interaction; next to search bar
- [ICON_UPLOAD] = ↑ upload arrow — upload/share file; file picker or editor
- [ICON_ENVELOPE] = ✉ envelope — mail/message; communication apps
- [ICON_MIC] = 🎤 microphone — voice input; search bar or keyboard
- [ICON_GOOGLE] = Google 'G' — Google account/service entry

### Operating Principles | #pull-on: stuck,complete,verify,retry,timeout,error
- Standard search pattern: tap search box → TYPE → ENTER (TYPE→ENTER is among the highest-frequency transitions)
- HOME is the most common first action; BACK for short undo; 3+ BACKs in a row means lost → HOME and restart
- Last action before completion is usually ENTER or tapping the target element — judge completion by meaningful screen change
